# Stardew-first visual review board: technical evidence vs artistic failure

Reference photographs/screenshots remain EXTERNAL: https://www.stardewvalley.net/press/ (primary color/character/foliage), https://www.necessegame.com/presskit (secondary readability/settlement scale). Graveyard Keeper is tertiary atmospheric inspiration. Never copy the original game sprites.

Real GODOT screenshots (not mockups): https://github.com/Stoffe101/PixelTown/actions/runs/38289008527 , Linux-godot-evidence artifact, including village, cave, 1080p/1440p/3440p showcase.

| Feature | Actual observation | Gate |
| --- | --- | --- |
| Cottage/forge | Rigid roof triangles and flat facades | FAIL |
| Grass/paths | Repetitive field noise and square-edged intersections | FAIL |
| Trees | Round repeated foliage shapes | FAIL |
| Characters | Too boxy, weak expressive frames | FAIL |
| Cave | Flat arena with repeated unbounded walls | FAIL |
| Shared prefab texture reimport | Five-tree runtime verification works | TECHNICAL PASS |

Two separate HAND-DRAWN CC0 source trials were inspected but not adopted:
- Ansimuz older RPG Town, artifact: https://github.com/Stoffe101/PixelTown/actions/runs/38288547421 . Too grainy and dense for this visual goal.
- Shade Puny World/Dungeon/Characters, artifact: https://github.com/Stoffe101/PixelTown/actions/runs/38289008527 . Coherent but too tiny/classic-RPG for our Stardew character/building richness.

Art Gate A remains FAILED. A beautiful new indie-game look requires actual original Aseprite painting by an artist, or a separately approved style-matched commercial asset pack legally usable with the public repository. CI pass is not aesthetic approval.
