# Visual Pilot: cottage (CC0 derivative)
Original sprite pixels by **Luis Zuno / Ansimuz**, released as **CC0 1.0** in [RPG Town Pixel Art Assets](https://opengameart.org/content/rpg-town-pixel-art-assets). This new cottage assembles the original tiled roof, wall and front-gabled modules at their **native pixel resolution**. It is a modified CC0 adaptation, not manually drawn original PixelTown artwork, nor the completed Stardew-inspired production style.

Do not conflate use of professionally-authored CC0 pixel art with creating original artwork. The new PNG is intentionally provided for honest side-by-side visual review before deeper expansion.
