# Playing PixelTown locally

On **GitHub Desktop**, select branch `prototype/art-direction-v1-00b`, click **Fetch origin** and **Pull origin**. The branch is an unmerged art prototype.

Open `C:\Users\Skrra\Documents\Projects\PixelTown\project.godot` in Godot **4.7.2**. Let it finish importing all textures. Press **F5** to run the existing main scene. The villager gathers, carries, works at the site and returns; the cave has a guard and looping slime encounter.

**Controls:** Tab village/cave, Space pause, R reset, F1 show controls, middle mouse drag pan, mouse wheel zoom, Esc return to village. For placing assets open `scenes/levels/village_layout.tscn` or `cave_layout.tscn` and drag prefabs into **Objects**; save with Ctrl+S. Play `scenes/levels/premium_asset_gallery.tscn` with F6 for a separate art inspection.

**Scope:** This is a working visual/demo sandbox, not a completed exploration RPG. Some animations remain provisional, other art sources lack genuine layered Aseprite masters, and the full visual acceptance gate remains open. All positions are stored in editor scenes, and external sprite textures stay shared.
