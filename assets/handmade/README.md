# PixelTown hand-authored artwork (tracked)

Save manually drawn, commercially original sprites here. PNG files added to this folder are **not ignored by Git**, unlike autogenerated preview sprites. To use a replacement, assign its texture in a `scenes/levels/*.tscn` or `scenes/props/*.tscn` Sprite2D node. Use exact pixel density (nearest filtering), transparent backgrounds and consistent foot anchors. Commit the PNG and relevant scene changes together.
